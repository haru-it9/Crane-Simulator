# 作業切替・復帰時の認知支援（ひな型）

`RemoteManagementScene(union)` の `TaskSwitchExperimentManager` に
`TaskSwitchCognitiveSupport` を追加済みです。支援内容の初期値は **両方** です。
矢印・フェーズは切替・復帰時に提示し、操作入力の解禁から設定時間を数えます。
コード既定値8秒、現在のシーン設定は1.5秒です。電流値は適正範囲に入ると緑色になります。
電流色モードがONの場合、適正範囲外の数値は通常色で表示し、数値をフェーズ色にはしません。
切替・復帰時に電流調整が必要なら「リフマグ電流」の見出しをフェーズ色にし、入力受付開始から白へフェードします。

## 条件の選択

Inspector の **Support Content** から選択します。

| 設定 | 内容 |
| --- | --- |
| Phase Only | フェーズのみ |
| Input Direction Only | 入力方向のみ |
| Phase And Input Direction | フェーズ＋入力方向 |

支援なしの比較をする場合は、このComponent自体を無効にします。
`Move1/Move2` は「移動」、`LiftUp` は「吊り上げ」、`Place/PlaceToTrack` は「配置」です。

## 表示開始・終了

- Target画面への実際の切替（`TargetDisplaySwitched`）と、Source画面への復帰
  （`SourceDisplayRestored`）で、そのフレームから表示します。要請・カウントダウン開始では表示しません。
- **Display Seconds** は操作解禁から完全に消え切るまでの時間です。コード既定値8秒、現在のシーン設定1.5秒です。
- 確認ボタン押下時点のTargetOperationStarted / SourceOperationResumedではタイマーを開始しません。
  ボタンを離して入力ロックが解除されるTargetInputUnlocked / SourceInputUnlockedを起点にします。同じ解禁イベントで延長しません。
- **Fade Out Seconds** はコード既定値0.75秒（0.5〜1秒で調整可能）、現在のシーン設定0.5秒です。
  現在は操作解禁1秒後から薄くなり、解禁1.5秒後に消え切ります。表示時間をフェード分だけ延長しません。
- 到達などで不要になった矢印も同じ秒数でフェードします。表示期限が先に来る場合はその時点で完全に消します。
  次のクレーンへの切替・実験終了・無効化では、前の操作指示を残さず即時クリアします。
- 確認待ち・ボタンを離すまでの待ち時間は、表示時間に含めません。待機中も矢印を提示します。
- 一時停止中も表示を保持し、停止時間は表示秒数に含めません。
- 次の切替・復帰では矢印のタイマーと電流支援の達成状態をリセットし、実験終了・再開始・無効化では非表示にします。
- 矢印は操作解禁を起点とする固定時間方式です。「入力が安定したら消す」判定はまだ実装していません。

## 位置・外観

Hierarchy の
`TaskSwitchUIRoot/TouchPanel/TextandButton/CognitiveSupport` 配下に置いています。

- `SupportPhaseText`: タイトルと操作パネルの間の初期配置。RectTransform・文字サイズ・色を調整できます。
- `SupportLeftX`: 横行を縦の矢印で表示します。横行ラベルは非表示です。
- `SupportRightY`: 上昇・下降を縦の矢印で表示します。上向き表示のラベルは「下降」、下向き表示は「上昇」です。
- `SupportRightZ`: 走行を横の矢印で表示します。走行ラベルは非表示です。

位置と大きさは各RectTransformで調整します。現在のシーンで設定済みの座標・サイズ・フェーズ文字色を使用します。
フェードは各グループのCanvasGroupで行い、矢印やラベルの元の色・アルファ値は変更しません。

移動と上下動を同時には推奨せず、その時点で必要な側だけ表示します。
左Xと右Zは、両軸が未到達なら同時に表示します。すべて Raycast Target をOFFにしてあり、既存Button操作を遮りません。
矢印はフォントの矢印文字ではなく `TaskSwitchSupportArrow` のメッシュで描きます。

## 方向・作業ステップ

矢印は現在の詳細ステップ、共通目標X/Z、InformationTargetの位置、着床、MainLifMagのlocal Yから更新します。
現在のレバー入力をそのまま示す表示ではありません。完了判定を変更することもありません。

- 移動: ステップのX/Z許容値を使い、未到達の軸だけ表示します。
- 配置前に位置がずれている場合: まず位置合わせを示し、下降を同時には示しません。
- 下降: 着床で下降矢印を消します。
- 上昇: ステップで定義されたlocal Y到達値まで表示します。
- 速度停止待ちなど: 移動矢印は表示しません。

### 電流の適正範囲と色

**Use Current Range Coloring**（既定ON）で電流色モードを選択します。
ONでは、入力方向を含む支援条件で、実験開始後の通常作業中も含め、現在の電流が適正範囲なら緑色、範囲外・判定不能なら通常色にします。
初回の切替・復帰イベントを待たずに開始し、カウントダウン中やフェーズ境界待ち中も更新します。
通常作業中は現在選択されているクレーンの作業フェーズと有効なLoadPlanを参照し、クレーン・フェーズ・目標の変更へ追従します。
通常作業の電流表示だけで矢印やフェーズパネルを開いたり、切替イベント・表示時間のタイマーを生成したりしません。
実験終了・未開始・無効化時は通常色へ戻します。切替確認待ちでは引き続き既存のCSV目標プレビューを使います。
着床状態から切り替えた場合もフェーズ色にはしません。表示中にこのモードをONにした場合もフェーズ色を解除します。
緑色は **Coordinate Color Source** の `CraneInformationDisplay.AchievedValueColor`（座標の目標範囲内の色）を直接参照します。
未指定時はシーン内のCraneInformationDisplayを自動取得します。座標側の色設定変更も電流表示へ反映されます。
参照がない場合も座標と同じ既定色 RGBA=(0.65,1,0.10,1) を使います。
保持重量の一致や上昇の完了を待たず、適正電流に入った時点で変化します。
色と上昇矢印は同じ電流判定を使います。

| 状態 | 電流の適正範囲（上下限を含む） |
| --- | --- |
| 目標重量が0t | 0Aのみ。+10Aの余裕は付けません |
| 目標重量が正、通常 | 目標重量(t) × 10A ～ その値 + 10A |
| 目標重量が正、厚板を保持し板山・台から十分に離れている | 目標重量(t) × 10A ～ 対象クレーンのMaximum Current Ampere |

通常の上限も対象クレーンのMAXを超えないようにします。例: 目標5t、MAX75Aなら、通常50〜60A、離床後50〜75Aです。
目標重量kgを1000で割ってtへ換算し、端数を丸めずに比較します。現在の保持重量や算出吊り上げ能力は電流適正判定には使いません。
0A判定は表示を丸める前の現在電流が0であることを使います。物理制御側の解除誤差は変更しません。
目標重量や電流、MAXが不明・非数値、または下限がMAXを超える場合は適正としません。

**Current Range Clearance** は保持板の下面から板山・台までの必要距離です。既定値は0.1ワールド座標単位
（1単位=1mの設定なら10cm）。下降停止と同じ読み取り専用BoxCastを利用し、保持中の板は除外します。
厚板保持中・非着床・距離が閾値以上の3条件を満たすと上限をMAXへ広げます。保持していない場合や距離不明時は広げません。
再び板山へ近づいた場合は通常の+10A上限へ戻ります。この距離は毎回更新し、山形矢印の固定個数とは独立です。

吊り上げの確認前はCSV目標、通常のSource復帰や操作開始後は現行LoadPlanを参照します。
配置では表示用の目標残存重量を参照し、0tなら0A、部分配置など0t以外なら上記の重量に応じた電流範囲を使います。
未確定の次フェーズに対して古い配置目標を流用しません。

### 切替・復帰時の「リフマグ電流」見出し

TaskSwitch UIの既存Text（`TextandButton/LifMagCurrent`）を **Current Input Label** に登録しています。
切替・復帰の瞬間に、吊り上げ・配置の電流調整または上昇段階で、電流不足・超過・0Aへの調整が必要な場合だけ、
この見出しをフェーズ文字と同じ色にします。既に適正な場合、目標不明の場合、まず位置合わせ・下降が必要な場合は白のままです。
判定は切替・復帰ごとに一度だけ行います。通常作業中に電流が範囲外へ出たり、切替後に着床しただけでは新たに強調しません。

対象クレーンの `ElectricCurrentInputAccepted`（実際の電流入力受付）を受け取ると、見出しを白へフェードします。
確認前・操作入力解禁前・電流再入力ロック中・一時停止中の入力は開始扱いにしません。
電流が適正になるまで待つのではなく、最初の受付時点から開始します。以後の入力でタイマーを延長しません。
**Current Input Label Fade Seconds** は既定0.75秒、Inspectorで0.5〜1秒に調整できます。
文字を透明にするのではなく、色を白（不透明）へ戻します。一時停止時間はフェードの経過に含めません。

矢印の表示時間が終わっても、入力開始までは見出しの強調を保持し、その後フェードします。
一度白へ戻った後は同じ区間で再強調しません。次の切替・復帰、クレーン変更、実験終了・無効化では前の強調と入力監視をクリアします。
フェーズのみ条件では見出し支援を出しません。電流数値の適正範囲・緑色表示は独立して継続します。

### 従来の着床開始時の数値強調（電流色モードOFFの場合のみ）

**Use Current Range Coloring** をOFFにすると、以下の従来方式を使用します。この場合、適正範囲による緑色表示は行いません。

フェーズ色による電流支援は、画面切替・復帰の瞬間に、対象クレーンの確定着床フラグ
（IsDownwardMovementBlockedByTouchdown）がONだった場合だけ有効です。
この対象判定は切替・復帰時に一度だけ保存し、その後の下降で着床しても強調を開始しません。
確認押下や操作解禁でも対象判定をやり直さず、次の切替・復帰で新しく判定します。

対象になった場合、吊り上げ・配置で必要な移動矢印がなく、着床済み、または重量吸着・解放ステップなら電流条件を確認します。

- 吊り上げ・配置とも、上記の適正電流条件を満たしていれば上昇を示します。
- この電流確認は着床後の補助案内だけでなく、Trackerが既に上昇ステップへ進んだ場合にも適用します。
  吊り上げ電流の不足・超過、目標重量や電流の不明・非数値では上昇矢印を出しません。既に出ていた矢印は既存設定どおりフェードします。
- 電流操作の段階に入ったら、電流値TextをSupportPhaseTextと同じ色にします。電流が適正になっても上昇達成まで保持します。
- 目標重量が不明なら上昇を推測せず電流値を強調します。上昇目標高さは同じクレーンのPhaseProfileを読み取り、既にその高さへ到達していれば上昇を再提示しません。
- フェーズのみ条件では入力方向・電流操作の支援を表示しません。

対象になった電流支援に時間制限はありません。Current Highlight Display Secondsの設定は廃止しました。
操作解禁後、実際の保持重量・板枚数がPhaseProfileの上昇ステップの条件を満たした状態で、実際に上昇した時点でフェーズ色の支援を終了します。
吊り上げは吸着目標重量、配置は配置計画の目標残存重量（通常0t）を使い、許容誤差も既存ステップと同じです。
上昇判定では、強調開始後の最下位置からMainLifMagのlocal Yが0.01以上増加し、そのフレームでも上昇していることを確認します。
誤重量で上がってから停止し、重量だけを合わせた場合には解除しません。正しい重量で改めて上昇する必要があります。
同じ切替・復帰の区間で一度達成した後はフェーズ色を再表示せず、元の通常色に戻します。
フェーズ色の対象判定は次の切替・復帰でやり直します。
矢印が消えた後も電流支援は継続しますが、電流条件の達成によって期限切れの矢印を再表示しません。
一時停止中は達成判定・色の更新を止めます。次の切替・復帰、実験終了・無効化では色をクリアします。
電流値・板の吸着状態・作業Tracker・入力ロック自体は変更しません。

確認押下前は、その実験で選択されたCSV条件を読み取り専用で参照します。
目標表示・作業Tracker・操作ロックは変更しません。Sourceがフェーズ境界で待機している場合は
再開予定のフェーズとそのCSV目標を使い、押下後は実際のTrackerへ追従します。
CSVなしで未来のランダム目標がまだ不明の場合は、古い目標を推測して移動矢印を出しません。

**Positive X Points Up / Positive Y Points Up / Positive Z Points Right** で
正の移動指令に対応する矢印を反転できます。初期値は現在のInputManagerと
CraneOperationManagerの符号変換（X=-Joystick3Vertical、Y=Joystick2Vertical、Z=-Joystick2Horizontal）を前提としています。
通常の非反転ジョイスティックY軸では手前側が正のため、初期値の上昇は下向き矢印です。
実機の軸・ドライバー設定が異なる場合は、この3項目で合わせてください。

## 入力方向の表示パターン

**Direction Presentation** は支援内容3条件とは独立して選択します。

| 設定 | 表示 |
| --- | --- |
| Single Arrow | 従来の大きな矢印 |
| Distance Chevrons | 切替・復帰時点の残り距離に応じた山形記号。1・2・3個の3段階 |

現在のシーンは **Single Arrow** です。個数方式を試す場合はDistance Chevronsを選びます。
フェーズのみ・入力方向のみ・併用の選択も引き続き使えます。
上下方向には山形記号を上下に、左右方向には「＞＞＞」「＜＜＜」の向きで並べます。
1個の記号の大きさは一定で、個数が少ない条件ほど表示全体が短くなります。位置と最大表示範囲は従来方式と共通です。

切替・復帰イベントのフレームで各軸の残り距離を一度だけ読み取り、個数を固定します。
表示中に近づいたり、確認ボタンを押したり、作業フェーズが変わったりしても再計算しません。
次の切替・復帰で、その時点の距離を使って新しい個数に更新します。
記号の向きと必要な軸の表示・非表示は従来どおり現在の作業状態に従うため、到達した方向は非表示になります。

切替・復帰時点の各軸の残り距離 d と **Distance Per Chevron** の設定 s を使い、
0 < d ≤ s は1個、s < d ≤ 2s は2個、2s < d は3個にします。
完了判定を満たした軸は個数0（非表示）です。入力の強さ・速度を指示する表示ではありません。

| 設定 | 初期値 | 距離の参照先 |
| --- | ---: | --- |
| X Distance Per Chevron | 0.5 | 横行。目標Xの許容範囲までの距離 |
| Y Distance Per Chevron | 0.5 | 上昇の目標高さ、または下降時の着床対象までの距離 |
| Z Distance Per Chevron | 2 | 走行。目標Zの許容範囲までの距離 |

距離はワールド座標単位です。上昇は詳細ステップのlocal Y閾値をワールド距離へ変換します。
下降は既存の下降停止と同じ形状・対象レイヤーでBoxCastし、最も近い対象面までの距離を参照します。
保持中の板は除外し、保持時にはBoard/BoardStageタグを親も含めて確認します。
これらは表示専用の読み取りで、移動・接触状態・着床イベントを更新しません。
切替・復帰時に対象面が検出できず下降距離が不明な場合は、方向のみを1個で示します。
上下動がその時点で必要でなかった場合も、上下の個数は1個として保持します。
この場合の1個は「近い」という距離の保証ではなく、ログのVerticalDistanceKnown=falseで識別できます。
このフラグも切替・復帰時点の取得状態であり、その後に対象面が見つかっても表示中の個数は変更しません。

表示開始・終了、停止中の扱い、レバー方向の反転設定は両方式で共通です。
既存の提示ログに表示方式・距離設定と、実際の各軸の表示個数を追記します。
ChevronCountAnchor=DisplaySwitch / ChevronCountsFixed=Trueで、切替・復帰時点に固定した個数であることを記録します。

## ログ

既存の `events.csv` に `CognitiveSupportShown` / `CognitiveSupportUpdated` /
`CognitiveSupportHidden` を出力します。条件・固定表示秒数・レバー対応・フェーズ・ステップ・
必要なXYZ指令・非表示理由を記録します。XYZは表示向きではなくCraneUnitの指令符号です。
FadeOutSecondsでフェード時間、CurrentGuidanceで電流不足・ゼロ待ち・上昇可能の提示状態を記録します。
DurationAnchor=InputUnlockedで時間の起点、CurrentHighlightEnd=CorrectWeightRaisedでフェーズ色の支援の終了条件を記録します。
CurrentHighlightEligibleAtSwitchで、切替・復帰時の着床状態による対象判定を記録します。
CognitiveSupportArrowTimerStartedで実際の解禁起点を記録します。
電流強調の開始はCognitiveSupportCurrentHighlightStarted、終了はCognitiveSupportCurrentHighlightEndedで、正しい重量での上昇時はReason=CorrectWeightRaisedです。
CurrentHighlightVisibleで強調の有無、CognitiveSupportHiddenで矢印・フェーズの終了を記録します。
CurrentRule=ZeroOrTargetTonnesTimes10ToPlus10A_ClearLoadToMaxとCurrentRangeClearanceで電流判定方式・離床距離を記録します。
CurrentColorMode=RangeStatusは適正範囲の緑色表示、TouchdownReminderは従来の着床開始時の強調です。
CurrentRangeExpandedは上限をMAXに広げた状態、CurrentAppropriateVisibleは緑色表示、CurrentHighlightVisibleはフェーズ色表示を示します。
CurrentGuidanceは不足時IncreaseCurrent、超過時DecreaseCurrent、ゼロ目標で非ゼロならSetCurrentToZero、判定不能時CurrentTargetUnavailable、適正範囲内ではReadyToRaiseです。
見出しはCognitiveSupportCurrentInputLabelShownで提示、CognitiveSupportCurrentInputLabelFadeStartedで入力受付を起点とするフェード開始、
CognitiveSupportCurrentInputLabelHiddenで終了を記録します。入力による完了はReason=InputAcceptedです。
他の実験イベント、入力ログ、操作判定を置き換えません。

`bash Tests/CognitiveSupport/run.sh` はMonoのmcs/monoで、方向判定、3条件、
画面切替前非表示、切替・復帰、解禁からの表示期限、正重量・板枚数での上昇判定、停止・無効化、シーン参照を検証します。
